# EconMark 首次试用指南

本指南用于第一次验证 EconMark 的完整工作流。建议先使用公开合成样例熟悉界面，再配置模型密钥并测试一份不含真实姓名的手写作答。

## 1. 启动前检查

要求 Node.js 22.5 或更新版本。在项目目录中运行：

```powershell
npm install
npm test
npm run check
npm start
```

看到以下信息即表示本地服务已启动：

```text
EconMark is running at http://127.0.0.1:4173
```

模型密钥尚未配置时，日志会提示 provider gateway not ready。这不会影响三个公开单份样例和 30 人合成班级；它只会阻止真实图片调用模型。

## 2. 第一次 30 人全自动批量评分（无需密钥）

打开 <http://127.0.0.1:4173/>，按以下顺序操作：

1. 点击“载入 30 人合成演示班级”。
2. 检查统一题目、命令词、总分和评分标准，点击“确认全班作业设置”。
3. 系统默认选择“全自动模式”；保持该选项以验证自动 OCR 放行、双评分、裁决、自动终审和反馈生成。
4. 点击“开始全班批量评分”。
5. 检查成功数、异常队列、分数分布和每位学生的“批注稿”。
6. 生成双语反馈包，检查每位学生的两项改进重点和一至两道针对性巩固题，再使用浏览器打印功能输出两栏 A4 反馈单。

如果评分按钮不可用，请依次检查：已经载入作答、全班作业设置已经确认，以及真实上传时账户已经登录。修改已确认的题目或评分标准会自动撤销确认，必须重新确认。

## 3. 可选：第一次单份评分（无需密钥）

打开 <http://127.0.0.1:4173/single.html>，按以下顺序操作：

1. 在“选择公开样例”中选择“中等作答”。
2. 对照合成手写图，检查并确认转写文本。
3. 检查并确认题目与评分标准。
4. 点击“开始证据锁定评分”。
5. 检查暂定分数、逐项引文证据、双语反馈和教师终审控制。

## 4. 第一次真实手写作答（需要模型密钥）

当前最简配置是一枚 DashScope/Qwen API 密钥。在启动 EconMark 的同一个 PowerShell 会话中设置：

```powershell
$env:DASHSCOPE_API_KEY="your-key"
npm start
```

如果服务器已经运行，先结束当前 `npm start` 进程，再在已设置密钥的同一终端重新启动。访问 <http://127.0.0.1:4173/api/providers/status>，确认顶层 `ready` 为 `true`；该接口只显示供应商和模型状态，不返回密钥。

随后：

1. 在页面右上角创建账户并登录。
2. 上传一份 JPG、PNG 或 WEBP 格式的单题手写作答。
3. 使用学生代号而不使用姓名、班级或其他直接身份信息。
4. 确认 OCR 转写和评分标准后运行评分。
5. 检查原图、转写、证据、分数、反馈和最终教师决定是否出现在账户历史中。

真实上传及其结果会永久写入 `.econmark-data/`，当前产品没有自动删除任务或删除 API。在学校批准所选 VPS、模型供应商和永久保存政策之前，不应上传真实学生作业。

### 手机连续扫描整班作答

手机必须通过 HTTPS 打开已部署的 EconMark；手机上的 `127.0.0.1` 指向手机自身，不能连接桌面电脑上的本地服务。登录后打开批量首页：

1. 点击“打开手机连续扫描”，首次使用时允许浏览器访问相机。
2. 每次将一名学生的一份完整作答放入取景框，按中央快门；相机会保持开启，可直接换下一份继续拍。
3. 拍错时点击“撤销上一张”，全部拍完后点击“完成”。
4. 在队列中检查顺序和清晰度，将自动生成的匿名编号改成所需学生代号。
5. 确认题目与评分标准后开始批量评分。

当前数据合同仍是一名学生对应一张图片。多页答卷应先使用手机的文档扫描功能合成为一张足够清晰的长图，或在后续多页作答版本中处理。若浏览器不支持连续相机，可使用“从相册或文件中添加”；新选择的图片会追加到当前队列，不会替换已经扫描的图片。

## 5. 首次试用的通过标准

- 首页和批量页均能正常打开，中文无乱码。
- 三个合成样例均能完成评分，且修改转写后不会引用不存在的证据。
- 30 人合成班级完成 30 份处理，单份失败不会中断整个班级。
- 最终分数只来自教师决定或已明确选择并通过置信门槛的全自动策略。
- 双语反馈的改进重点一致，每位学生包含一至两道与具体弱点相关的巩固题。
- 未配置模型密钥时，公开样例可运行，而真实上传会给出明确的配置提示。

## 6. 常用健康检查

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:4173/api/config
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:4173/api/providers/status
Get-Content -Tail 50 -Encoding UTF8 .econmark-server.out.log
Get-Content -Tail 50 -Encoding UTF8 .econmark-server.err.log
```

`/api/config` 应返回服务器实际批量容量和文件限制。默认设置为单文件 32 MB、单批 100 份、单批总量 512 MB、并发 4 和单账户永久存储 50 GB。
