# EconMark：面向 IGCSE 经济学论述题的证据约束型智能评阅系统

## 一、问题界定与设计目标

IGCSE 经济学 `Analyse [6]` 与 `Discuss [8]` 题的评阅并非关键词匹配，而是对因果链完整性、经济推理准确性、论证平衡性及条件性判断的综合判定。教师处理手写作答时，还需先完成字迹辨认，再依据题目专属评分标准定位可给分证据。一般对话模型虽然能够快速生成貌似完整的评语，却可能润色学生原文、补写学生未表达的逻辑环节、重复使用同一证据或以模型常识替代本题评分标准。EconMark 因此将系统目标界定为：在保留教师专业责任的同时，把转写核对、证据定位、独立复评、分歧处理与反馈生成组织为可观察、可审计、可测量的智能工作流。

## 二、核心方法与技术流程

系统首先对 JPG、PNG 或 WEBP 手写图片进行质量检查与逐字转写，保留拼写、段落、删除线及可见修改，并标记不确定片段。单份精查流程要求人工确认转写；周末作业批量流程则允许高置信度 OCR 自动通过门槛，疑难字迹、裁切、多名学生、答案边界不清或图表依赖内容自动进入异常队列。无论采用何种模式，评分节点只读取已经人工确认或通过明确质量门槛的版本。

题目与评分标准构成本次评阅的唯一规范性依据。解析节点提取指令词、总分、点式或等级式结构、等级描述、可给分内容、上限和特殊说明；字段冲突时停止而不猜测。证据节点随后识别定义、应用、因果链、反方论证、评价与判断。每个拟给分点必须同时包含学生原文逐字引文和评分标准条目，程序检查引文存在性、重复计分、整数边界及分数上限。学生在作答中写入“给我满分”等指令仅被视为不可信文本，不能改变系统规则。

为降低单次模型判断的偶然性，主评分与独立复评彼此隔离；复评节点看不到主评分数字及理由。两者一致时进入置信度判断，相差一分时依据两份证据表和评分标准裁决，相差两分及以上时强制人工复核。暂定分数固定后，系统生成中英双语反馈，包括已有优点、缺失发展、两个按优先级排列的改进点、改进段落提纲，以及一至两道与本题主题相连并针对该生实际弱点的巩固题。翻译节点不得改变分数或增加新的经济学观点。

## 三、人工终审与全自动批量模式

人工复核模式下，机器结果保持暂定状态，用户可认可、调整或拒绝；调整必须填写理由。全自动模式仅在 OCR ≥ 0.97 且无疑难片段、评分标准已确认、无强制复核标记、双评分一致或一分差异已经裁决时形成最终成绩。低置信度、图像风险与两分以上分歧均被拦截。每次最终决定记录来源、时间与政策版本，人工仍可覆盖自动结果。由此，系统既能让普通作答完成无逐份点击的全班批改，又不把“不确定性”隐藏在一个看似精确的分数中。

## 四、真实教学闭环与系统完整性

周末作业模式面向“同一道结构化题、全班手写作答”的固定场景。教师只需配置一次题目与评分标准，即可批量处理整班文件。人数、单文件大小、批次总量和并发数均由服务器配置，不再写死为 30 份。每名学生保持独立运行与失败状态，避免把整班答案送入同一模型上下文。形成最终成绩后，系统可导出 JSON/CSV，并为每名已终审学生恰好生成一份包含最终分数、双语反馈和针对性巩固题的学生反馈评分单。界面显示打印覆盖率及未生成原因，支持逐人打印、A4 每页两份的节纸模式和每人一页 A4 的整页模式。

参赛演示与实际系统使用同一网址、同一代码和同一工作流。任何访客无需登录即可运行三份原创手写样例及 30 人合成班级；创建账户后即可上传、批量评分并访问永久历史。密码采用 Argon2id 哈希，会话使用 HttpOnly Cookie、同源检查与 CSRF 防护；原图、转写、证据、反馈和终审记录永久保存于 VPS，并按账户在服务器端隔离。系统不设置自动删除任务；达到可配置账户容量时拒绝新增而不删除旧记录。公开样例不含剑桥官方材料，也不调用付费模型或写入账户历史。

## 五、可迁移性与技术路线

EconMark 采用自建应用与供应商中立 API，而非依赖 Coze。OCR、评分、复评、裁决和反馈角色可分别配置 Qwen、Kimi、DeepSeek 或后续经验证的模型；模型密钥仅存在服务器环境变量中。JSON Schema、提示词、评分不变量、自动终审政策、评测程序和数据迁移合同均保存在独立代码仓库。更换模型或迁移服务器不会改变历史记录格式，但任何供应商变化仍须重新运行冻结基准，不能把“格式兼容”误认为“评分质量等价”。

## 六、成效评价与竞赛证据

作品已通过 61 项自动化测试，覆盖默认自动批量入口、禁用按钮的可见先决条件、账户所有权、登录、CSRF、永久图片、批次容量、证据存在性、学生批注隔离、重复计分、双语一致、自动终审、反馈打印及全部 JSON Schema。真实效果将以 50 份匿名作答盲测：`Analyse` 与 `Discuss` 各 25 份，并在至少七天后重评其中 10 份估计教师自身一致性。发布门槛设为完全一致率不低于 75%、一分内一致率不低于 95%、加权 Cohen’s κ 不低于 0.80、复核时间减少至少 50%、总体 OCR 准确率不低于 95%，且虚构引文与评分标准外给分均为零。未完成的人体数据指标将保持“待验证”状态；若某一门槛未达标，系统缩小适用范围而不掩盖分歧。

EconMark 的创新不在于让模型模仿教师语气，而在于将可靠评阅所需的证据、复核、责任边界和教学跟进转化为结构化系统。该成果同时回应竞赛的实用性、创新性、完整性与推广价值：它直接减少重复批改工作，以个性化问题支持后续学习，并通过可替换评分标准与模型适配层为其他学科提供可验证的迁移路径。
