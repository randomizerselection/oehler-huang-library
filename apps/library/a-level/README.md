# A Level Economics public course

The course page links the active Cambridge International AS & A Level Economics
9708 lessons. `lessons/` and `shared-html/` are the authoritative editable sources
and are served directly by the platform. No copy or synchronization step is needed.

Planning workbooks, teaching preferences, retained PowerPoint references, source
audits and portable HTML export/check scripts are in `authoring/a-level/` at the
repository root. See `authoring/README.md` for commands. Use `npm start` for preview.

The standalone `a-level` project is a deprecated recovery copy. Unlinked lessons
and unused slide types are legacy references. New lessons follow the linked HTML
decks and are added to this course landing page when ready.
